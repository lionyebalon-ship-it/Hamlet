# Instructions for coding agents

Before making changes, read [README.md](README.md) and
[docs/PROJECT_STATUS.md](docs/PROJECT_STATUS.md). The status document records
the current implementation, verified behavior, known limitations, and
prioritized next work.

Do not treat planned features as implemented. In particular, live AI
integration, persistence, the Memories UI, and autonomous villager movement
are not implemented; room pathfinding is groundwork, not in-game NPC movement.

After completing a meaningful milestone, update the project status document and
README where relevant. Check the existing worktree before editing, preserve
unrelated user changes, and run the narrowest relevant tests.
